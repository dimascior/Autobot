## Layout

- `phase-a/` — the frozen Phase A discovery record (handoff
  `ch01-phase-a.json`), preserved as history; the acceptance gate checks
  this tree against its registries.
- `registries/` — machine-readable truth: decisions, enums, identifiers,
  representation coverage (all 42 objects), semantic rules (SEM-01..SEM-19),
  vector resolutions, traceability (all 76 invariants), the review record.
- `schemas/` — v1 JSON Schemas (authoring profile) for the 10 Chapter-1-required
  objects: obj-00, obj-02, obj-03, obj-04 (with embedded obj-05/06/07/17),
  obj-18, obj-32.
- `contract_library/` — the contract library (import name `contract_library`,
  formerly `src/autobot_contract`): canonicalization (RFC 8785 JCS subset per
  D-24), domain-separated digests, identifier grammar, structural + semantic
  validation. Stdlib only (D-59).
- `vectors/` — fixtures and the frozen golden digests (generated by the
  library, re-verified by an independent JCS implementation and across
  processes; byte-identical through the refinements and the restructure).
- `harness/` — conformance tests (positive, negative, property, cross-process),
  the independent JCS implementation, `run_all.py`, `check_chapter1.py`, and
  planted-defect tests for the checker itself.
- `CHAPTER1_SPECIFICATION.md` — normative prose, checked against the registries.
- `DECISION_PACKAGE.md` — the consolidated operator review of D-19..D-61.
- `CONSOLIDATED_REVIEW.md` — the 2026-11-08 ratification review, with the
  2026-11-09 post-ratification addendum.
